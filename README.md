# 🐍 Inventory-Trax

## Python Inventory Management System

## Overview

Inventory-Trax is a command-line inventory management application developed in Python. The application allows users to add, update, remove, search, and view inventory items while demonstrating Python fundamentals, menu-driven programming, list-based data storage, dictionaries, functions, and basic CRUD operations.

Originally developed as part of a graduate Python programming course, this project is included in my portfolio to demonstrate foundational programming skills and practical application development.

---

## Features

- Add new inventory items
- Update existing inventory quantities
- Remove inventory items
- Search inventory by item name
- View an inventory summary
- Display low-stock alerts when quantity falls below the threshold
- Menu-driven command-line interface
